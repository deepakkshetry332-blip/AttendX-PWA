🚀 Deploy on Vercel via Phone (Koder + GitHub)
Complete guide to deploy AttendX using your phone
```
1
Set Up GitHub on Your Phone
Download the GitHub mobile app. Create a free account at github.com. Create a new repository named attendx-pwa (set to Public).
2
Install Koder (Code Editor App)
Download Koder from the App Store (iOS) or use Acode on Android. These are mobile code editors that support file creation and GitHub sync.
3
Create Your Project Files
In Koder/Acode, create 3 files in a new folder:
📁 attendx-pwa/ ``` ├── index.html ← (paste the full PWA code) ├── manifest.json ← (see below) └── sw.js ← (see below)
```
4
manifest.json Content
{ ``` “name”: “AttendX”, “short_name”: “AttendX”, “description”: “Smart Attendance Tracker”, “start_url”: “/”, “display”: “standalone”, “background_color”: “#060b18”, “theme_color”: “#00e5ff”, “icons”: [ { “src”: “https://via.placeholder.com/192x192/00e5ff/000?text=AX”, “sizes”: “192x192”, “type”: “image/png” }, { “src”: “https://via.placeholder.com/512x512/00e5ff/000?text=AX”, “sizes”: “512x512”, “type”: “image/png” } ] }
```
5
sw.js (Service Worker)
const CACHE = 'attendx-v1'; ``` const ASSETS = [’/’, ‘/index.html’, ‘/manifest.json’]; self.addEventListener(‘install’, e => { e.waitUntil(caches.open(CACHE).then(c => c.addAll(ASSETS))); }); self.addEventListener(‘fetch’, e => { e.respondWith(caches.match(e.request).then(r => r || fetch(e.request))); });
```
6
Push to GitHub
In Koder, connect to your GitHub repo using your Personal Access Token (generate at GitHub → Settings → Developer Settings → Personal Access Tokens). Commit and push all 3 files.
7
Deploy on Vercel
Go to vercel.com on your phone browser. Sign in with GitHub. Click "Add New Project" → import your attendx-pwa repo. Framework Preset: Other. Click Deploy. Done! You'll get a live URL like attendx-pwa.vercel.app
8
Configure Firebase Rules
In Firebase Console → Firestore Database → Rules, paste these rules:
rules_version = '2'; ``` service cloud.firestore { match /databases/{database}/documents { match /users/{userId} { allow read, write: if request.auth.uid == userId; } match /classes/{classId} { allow read: if request.auth != null; allow write: if request.auth != null && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == ‘admin’; } match /sessions/{sessionId} { allow read: if request.auth != null; allow write: if request.auth != null && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == ‘admin’; } match /attendance/{recordId} { allow read, write: if request.auth != null; } match /settings/{doc} { allow read: if request.auth != null; allow write: if request.auth != null && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == ‘admin’; } } }
```
9
Enable Firebase Auth
In Firebase Console → Authentication → Sign-in Method → Enable Email/Password. Also enable Firestore Database in your project.
10
Install as PWA on Phone
Open your Vercel URL in Chrome (Android) or Safari (iOS). Tap the Share/Menu button → "Add to Home Screen". AttendX will install like a native app with offline support!
⚠️ Important Security Note
Your Firebase API key is embedded. For production, add your Vercel domain to Firebase Console → Project Settings → Authorized Domains. This prevents unauthorized API usage from other origins.
